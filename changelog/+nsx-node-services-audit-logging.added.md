Extended ``vcf_nsx_node_services`` with generic ``service_get`` / ``service_set`` verbs and ``manager`` / ``policy`` / ``async_replicator`` wrappers, plus a new ``logging_level_configured`` state that idempotently sets ``service_properties.logging_level`` on the four NSX node services (``async_replicator``, ``http``, ``manager``, ``policy``) — the API equivalent of ``set service <name> logging-level <level>`` for STIG 912 audit logging.
