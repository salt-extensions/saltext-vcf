Extend `vcfa_lifecycle` client / `vcf_vcfa_lifecycle` exec module with patch-baseline management: `list_patches`, `installed_patches`, `available_patches`, `stage_patch`, `apply_patch`, and helpers to compare installed patches against a caller-supplied allowed baseline list. Adds a `vcf_vcfa_lifecycle` state module with `patch_present` (idempotent enforcement — applies a patch when the product is not at an allowed version) and `baseline_check` (read-only compliance check) so operators can enforce a TSC-approved patch baseline via Salt states.
